# Literature Verification

Build an evidence matrix with claim, precise primary-source locator, verifiable support, status VERIFIED/UNVERIFIED/CONTRADICTED/OPEN, and overlap with proposed contribution. Search synonyms and equivalent formulations. If sources cannot be independently checked, mark UNVERIFIED; publication novelty gate STOP.

Deliver a concrete artifact or table, not only a persuasive narrative. Explicitly separate observed evidence, hypothesis and human judgment. Cite sources by stable URI and run evidence by file path/hash.
