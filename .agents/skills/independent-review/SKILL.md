# Independent Review

Using raw artifact IDs, protocol and evidence matrix only, recompute metrics when possible; inspect gates and validity. Produce claim/reasons/evidence/counterarguments/warrant, limitations and decision GO/REVISE/STOP. Reject fabricated results and unsupported novelty.

Deliver a concrete artifact or table, not only a persuasive narrative. Explicitly separate observed evidence, hypothesis and human judgment. Cite sources by stable URI and run evidence by file path/hash.
