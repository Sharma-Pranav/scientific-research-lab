# Hypothesis Generation

Write topic/question/reader significance; propose H0, H1, H2 alternative mechanism, and H3 artifact. For each specify an observation that would refute it, boundary conditions and a low-cost discriminating experiment. Do not assert idea novelty.

Deliver a concrete artifact or table, not only a persuasive narrative. Explicitly separate observed evidence, hypothesis and human judgment. Cite sources by stable URI and run evidence by file path/hash.
