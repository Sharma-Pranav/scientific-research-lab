# Hypothesis Generation

Before building an experiment, write the precise three-step statement:
"I am studying ... because I want to find out ... in order to help my reader understand ...".
Identify the actual external reader and the understanding or decision affected; reject author-centered
reasons such as "to build a model", "to get a paper", or vague "because it is important".
Use the scaffolded significance.md and require a passed framing preflight before declaring
the question ready for scientific review; the checker measures structure, not importance.

Then write topic/question/reader significance; propose H0, H1, H2 alternative mechanism, and H3 artifact. For each specify an observation that would refute it, boundary conditions and a low-cost discriminating experiment. Do not assert idea novelty.

Deliver a concrete artifact or table, not only a persuasive narrative. Explicitly separate observed evidence, hypothesis and human judgment. Cite sources by stable URI and run evidence by file path/hash.
