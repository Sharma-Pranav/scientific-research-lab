# Experiment Design

Specify dataset provenance/fingerprint, splits, target metric, strong baselines and tuning budgets, seeds, uncertainty method, ablations, sensitivity and leakage checks. Log exploratory iterations. Freeze confirmation protocol before execution. Document compute and non-identifiable factors.

Deliver a concrete artifact or table, not only a persuasive narrative. Explicitly separate observed evidence, hypothesis and human judgment. Cite sources by stable URI and run evidence by file path/hash.
