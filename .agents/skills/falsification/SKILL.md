# Falsification

Check leakage, metric choice, weak baselines, random seeds, confounds, data selection, compute imbalance, hyperparameter budget, publication bias and failure regimes. Propose a counterexample with expected result and a reproducible test. Preserve failed outcomes.

Deliver a concrete artifact or table, not only a persuasive narrative. Explicitly separate observed evidence, hypothesis and human judgment. Cite sources by stable URI and run evidence by file path/hash.
